BEACHCAR · LOCAL CODEX SETUP

This package connects your own Codex desktop app to your Beachcar account.
Beachcar does not receive your marketplace password, and this setup does not
turn on Beachcar-paid AI or authenticated cloud-browser scraping. Codex may
read Beachcar's small public auction-feed cache before using your browser.

Before you start

1. Install and sign in to the Codex desktop app on this Mac.
2. Open Beachcar in your desktop browser with the same email you used on the
   iPhone.
3. In Beachcar's Local Codex connection panel, create a recurring token. It is
   shown only once, so keep that browser page open.

Install

1. Double-click “Install Beachcar.command”. If macOS asks, Control-click the
   file, choose Open, and confirm that you want to open it in Terminal.
2. When Terminal asks for the Beachcar token, paste the one-time token and
   press Return. It will not be displayed while you type or paste.
3. Wait for “Beachcar is connected to local Codex,” then quit and reopen Codex.
4. In a new Codex task, paste:

   Use the Beachcar skill. Start my first-run taste calibration, ask for my
   confirmation before saving it, then use my logged-in local browser to
   research and publish a small first shortlist through Beachcar MCP. Do not
   enable managed research or record local Codex costs.

For the first run, stay nearby so you can complete any marketplace sign-in,
MFA, CAPTCHA, or consent screen. Only schedule the recurring task after Codex
publishes a shortlist and verifies the same run in Beachcar. The Mac must be
awake and Codex must be running at the scheduled time.

The recurring token can read Beachcar setup and sources, save a confirmed
taste calibration, publish and verify runs, and read automation events. It
cannot bid, buy, delete the account, start paid research, or write AI usage.
You can revoke it from Beachcar at any time.
